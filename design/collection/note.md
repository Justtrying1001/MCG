# Collection Page Notes

This is the core gameplay screen.

## Layout

* left sidebar navigation
* top bar (user, currency, actions)
* main grid of cards
* right panel for selected card

## Behavior

* cards = real user-owned assets
* filters must stay functional
* clicking a card updates detail panel

## Design Intent

* feel like a collectible gallery
* immersive and playful
* strong depth and layering

## Priority

This page must be pixel-perfect.
