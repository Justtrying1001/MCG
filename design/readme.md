# MCG Design Reference (Stitch)

This folder contains the visual reference for the full UI redesign of the app.

---

## Structure

Each page folder contains:

* screen.png → visual reference from Stitch
* code.html → exported HTML (reference only, DO NOT copy)

---

## Global Design System

See: DESIGN.md

This defines:

* visual language
* layout rules
* components
* interactions

---

## Important Rules

* HTML files are reference only
* DO NOT copy/paste HTML into the app
* Rebuild UI as clean React components
* Preserve backend, API, auth, and data flows

---

## Key Constraint

This is a **UI refactor**, not a rewrite.

Do NOT:

* change routes
* break API calls
* modify business logic

---

## Goal

Match the Stitch design as closely as possible while keeping the app fully functional.

---
