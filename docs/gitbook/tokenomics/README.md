# Tokenomics

This section explains how the MCG token is launched, why it exists, and how it will be integrated into the game over time.

## General overview

MCG uses a **fair and public launch** model.

The token was launched through Bagsapp on Bags.fm, with:

- no private investors,
- no pre-sale,
- no team allocation.

The full supply was put into public circulation with the same starting conditions for everyone.

The token's role is to help bootstrap MCG development. Trading fees generated on DEX markets are intended to support faster product development.

The token will also be integrated progressively into gameplay. Over time, it is expected to become a core in-game currency for actions like pack purchases, contest participation, and other ecosystem features.

We keep utility communication intentionally simple: the token is designed to be central and useful to the MCG community, while exact implementations are rolled out in stages.
