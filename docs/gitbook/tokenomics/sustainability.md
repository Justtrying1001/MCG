# Sustainability

## Development support

The token is part of MCG's long-term build strategy.

A share of value generated by token trading activity on DEX markets is intended to support ongoing development and product improvements.

## Long-term ecosystem focus

MCG's objective is not short-term token hype. The objective is to build a durable game ecosystem where token utility grows with real product usage.

## Practical approach

Utility details will be announced progressively, with delivery-first communication.

This keeps expectations grounded while reinforcing the token's long-term role in the MCG economy.
