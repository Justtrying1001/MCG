# MCG Documentation

Welcome to the official MCG documentation.

This guide is designed for two audiences:

- **Players**, who need practical instructions to start collecting cards, entering tournaments, and earning rewards.
- **Investors and ecosystem participants**, who need a clear view of how MCG systems, token flows, and sustainability mechanics work.

The documentation is organized from fundamentals to advanced topics:

1. **Introduction** for context and core vision.
2. **The Game** for all gameplay systems and economy loops.
3. **Tokenomics** for utility, distribution logic, and sustainability.
4. **Ecosystem** for market interactions, community, and governance direction.
5. **Roadmap** for execution priorities.
6. **FAQ** for common operational questions.

Use the sidebar to navigate page by page.
