# Tournaments

## Tournament lifecycle
MCG tournaments run through status phases:

- **DRAFT**: admin setup phase
- **OPEN**: players can enter lineups
- **LOCKED**: lineups are frozen
- **LIVE**: tournament is active
- **SETTLED**: scoring finalized and rewards distributed
- **CANCELED**: event canceled

## Entry process
1. Open a tournament in `OPEN` status.
2. Verify lineup rules and eligibility requirements.
3. Select cards from your collection.
4. Confirm entry (entry fees may apply depending on config).

## Scoring fundamentals
Scoring is based on contest runtime data and configured multipliers, including:

- Start and end market snapshots
- Rarity multipliers
- Edition multipliers

## Competitive best practices
- Build lineups around rule-specific upside, not only highest rarity.
- Confirm lock times (`lockAt`) to avoid missed entries.
- Diversify entries if the format allows multiple strategic approaches.
