# Packs

## What packs are
A pack is the primary acquisition unit in MCG. Opening one pack grants **5 cards**.

## Pack opening flow
1. Check pack availability and price.
2. Confirm you have enough balance/points.
3. Open a pack.
4. Receive 5 cards in your collection.
5. Transaction and reward events are recorded in the ledger.

## Key mechanics
### Availability
Packs are finite and linked to remaining card supply.

### Randomized distribution
Card outcomes are generated by runtime draw logic and configured slot/weight rules.

### Cost and pacing
Pack cost creates the main entry gate for collection growth. Monitoring cost versus expected tournament value is important.

## Good operational practices
- Open packs during active tournament windows when new cards can be used immediately.
- Track pack config updates before making large acquisition decisions.
