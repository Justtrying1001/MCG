# Vision

## Long-term objective
MCG aims to become a transparent, skill-based collectible competition layer for Web3 communities.

## Design principles
### Clarity first
Rules, scoring, and distribution logic should be understandable and auditable.

### Utility over speculation
Game assets should provide recurring gameplay utility, not only passive holding value.

### Measurable progression
Players should see a clear path from onboarding to advanced competition.

### Sustainable loops
Reward output should stay aligned with participation quality and economic controls.

## Expected evolution
MCG is expected to grow from a Genesis collectible and tournament model toward a broader ecosystem including marketplace activity, stronger social features, and governance input.
