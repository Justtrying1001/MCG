# Preamble

## Purpose of this documentation
This documentation explains how MCG works at a system level and at a user level.

It focuses on:

- Core gameplay loops
- Asset mechanics and ownership logic
- Tournament and reward design
- Economy and token model
- Operational expectations for users and stakeholders

## Who should read this
### New players
Read this if you need a clear onboarding path from account setup to tournament participation.

### Existing players
Read this to optimize decisions around pack opening, roster building, and reward cycles.

### Investors and partners
Read this to understand emission controls, utility flows, and sustainability assumptions.

## Scope
This GitBook covers product and economic mechanics. It does not replace legal, tax, or financial advice.

## How to use this guide
1. Read Introduction and The Game in order.
2. Use Tokenomics and Ecosystem for deeper strategic understanding.
3. Use FAQ for practical operational issues.
