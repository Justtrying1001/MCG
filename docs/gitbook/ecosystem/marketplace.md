# Marketplace

## Marketplace purpose
The marketplace allows players to buy and sell cards based on strategy, scarcity, and tournament utility.

## Primary functions
- List cards for sale
- Buy cards from other players
- Rebalance collection composition without relying only on pack openings

## Market drivers
Card price dynamics are commonly influenced by:

- Tournament eligibility demand
- Rarity and edition premiums
- Overall player activity
- Reward cycle timing

## User guidance
- Buyers should evaluate utility first, then rarity premium.
- Sellers should monitor tournament calendars before listing high-utility cards.
- Both sides should account for any applicable transaction fees.
