# 00 — Mememon TCG Overview

## What Mememon TCG is
Mememon TCG is a web3-native collectible trading card game where memes, tokens, crypto communities, and internet-native IP are represented as collectible cards with tournament utility.

Mememon TCG is the first revenue-facing product of Outerplay Studio.

## What players do
1. Acquire cards through packs.
2. Build and grow a collection (Memedex).
3. Use eligible cards in Weekly Tournament lineups.
4. Track rankings and rewards outcomes.

## Collectible model
- Product direction: editions are the active scarcity/collectible tier.
- Runtime currently still contains rarity + edition systems; rarity remains a legacy-active runtime dependency pending cleanup.

## Stage framing (non-mixed)
| Stage | Scope summary |
|---|---|
| Current Reality | Pack, collection, and contest foundations exist in runtime. |
| Internal Demo | Controlled walkthrough priority; must be reliable and wallet-friction-light. |
| Alpha | Private tester stability around the same core loop. |
| Beta | Broader activation and stronger operations/economy clarity. |
| V1 | First market launch target, including mature monetization/trading decisions. |
| Post-V1 | Advanced tournament types, trading depth, and web3 extensions. |

## Not live in current reality
- Live marketplace / secondary trading.
- Real-money pack checkout.
- Paid tournament entry and prize pools.
- Mandatory on-chain ownership enforcement.
