# Demo 05 — Demo Limitations

## Purpose
Prevent overclaiming and reduce demo execution risk.

## Confirmed limitations
- Marketplace flows are not live in current runtime.
- Real-money pack checkout is not live.
- Paid tournament entry fees/prize pools are not live.
- Mandatory on-chain ownership enforcement is not live.

## Demo-specific risks
- Wallet path exists but should not be the only entry path for investor demo.
- Contest lifecycle state can block lineup actions if unprepared.
- Demo quality depends on seeded pack supply, points balances, and contest states.

## Mandatory disclosure in demo narration
State explicitly that current demo demonstrates collectible + tournament utility loop, while marketplace/payments/paid tournaments/on-chain enforcement are future-scoped.
