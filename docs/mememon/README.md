# Mememon TCG Documentation (Official Source of Truth)

`docs/mememon/` is the only official Mememon TCG product documentation set.

## Scope and intent
- Keep one clean documentation base for investors, operators, and builders.
- Separate **Current Reality** from **Internal Demo**, **Alpha**, **Beta**, **V1**, and **Post-V1**.
- Avoid overclaiming marketplace, payments, paid tournaments, or on-chain readiness.
