# Welcome to MCG

**MCG — Meme Card Game** is a crypto trading card game built around meme tokens.

Collect cards, build rosters, and compete in contests where real on-chain performance determines your score. Every card represents a real meme token. Every contest is a live market battle.

---

## What you'll find here

This documentation covers everything you need to know to play MCG — from opening your first pack to understanding how scoring works, how to progress, and what the MCG token brings to the ecosystem.

> ⚠️ **This is a living document.** MCG is in active development. Features, mechanics, and numbers may evolve. See the [Preamble](preamble.md) for more context.
