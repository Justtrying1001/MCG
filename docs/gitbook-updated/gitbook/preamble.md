# ⚠️ Preamble — MVP & Living Document

## We're in early days

MCG is currently in **MVP** (Minimum Viable Product) stage. This means the core experience is live and playable — but it also means the project is evolving fast.

We're building MCG in the open, iterating based on real feedback from real players. Some mechanics will be refined. Some features are still being designed. Some numbers will change.

---

## What this means for you

- **This documentation will be updated regularly.** As the game evolves, so does this doc. Treat it as a living reference, not a final rulebook.
- **Some things are intentionally vague for now.** Certain systems are subject to change and will be clarified as they stabilize.
- **Your feedback matters.** If something feels off, unclear, or broken — we want to know.

---

## What's stable

The core loop is established:

- Collecting cards through packs
- Building rosters for contests
- Scoring based on token market performance
- Earning points and progressing through milestones

These foundations won't change drastically. The refinements happen around the edges.

---

## What's coming

MCG is a project with a long roadmap. Among the things being actively worked on or planned:

- Expanded card sets beyond Set 1 GENESIS
- New contest formats and modes
- Trading and secondary market features
- Full token integration into the ecosystem

We'll document things as they ship — not before.

---

> **In short:** join early, expect iteration, and know that the best version of MCG is being built right now.
